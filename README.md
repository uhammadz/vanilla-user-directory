# 📇 Vanilla JS User Directory & Analytics

A responsive, lightweight web application built with pure **Vanilla JavaScript** that fetches live user data, provides real-time search filtering, and calculates array analytics.

## 🚀 Live Demo
[Link Live Demo di Vercel/Netlify](https://your-demo-link.vercel.app)

## ✨ Features
- **Async Data Fetching**: Retrieves user data dynamically from JSONPlaceholder REST API using `async/await`.
- **Real-Time Search**: Filters users instantly by name utilizing ES6+ `.filter()`.
- **Data Analytics**: Calculates aggregate stats (character counts, domain filtering) using `.map()` and `.reduce()`.
- **Responsive UI**: Styled with CSS Grid and smooth hover transitions.
- **Loading State**: Visual feedback during asynchronous network requests.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Grid & Flexbox)
- **JavaScript** (ES6+, Fetch API, Async/Await)
